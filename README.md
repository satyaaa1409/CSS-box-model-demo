# CSS Box Model Demo

A simple HTML/CSS project built to understand and demonstrate the **CSS Box Model** — one of the most fundamental concepts in web design.

## 📌 What it covers
- The four components of the box model: **content, padding, border, and margin**
- Practical styling using `margin`, `padding`, `border`, and `background-color`
- Difference between **inline** and **block-level** elements (`strong` vs `div`/`p`)
- Basic use of **nested CSS syntax**

## 🛠️ Built With
- HTML5
- CSS3 (native nesting)

## 🎯 Purpose
This project was built while learning CSS fundamentals — moving from HTML into structured, styled layouts. It focuses on getting hands-on with the box model before moving on to Flexbox and Grid.
